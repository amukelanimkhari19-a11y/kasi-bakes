## Project Overview

A fully functional, responsive, and SEO-optimised website for **Kasi Bakes**, an artisan bakery based in Mofolo, Soweto, Gauteng, South Africa.

---

## Website Goals and Objectives

- Establish a professional online presence for Kasi Bakes.
- Increase online orders and enquiries by 30% within six months of launch.
- Showcase the full product catalogue with images and pricing.
- Enable customers to submit bulk and custom order enquiries online.
- Improve visibility in Google search results for bakeries in Soweto.

### Key Performance Indicators (KPIs)
- 500+ unique monthly visitors within 3 months.
- 20+ enquiry form submissions per month.
- Average session duration of 2+ minutes.

---

## Key Features and Functionality

- Responsive layout — mobile, tablet, and desktop.
- Navigation menu linking all 5 pages.
- Product catalogue with images, descriptions, and prices.
- Enquiry form with order type, date picker, and delivery options.
- Contact page with two location maps and a contact form.
- SEO meta tags on all pages.
- CSS Grid and Flexbox layout structure.
- Hover and focus pseudo-class interactions.

### Responsive Breakpoints
| Breakpoint | Screen Size | Layout Changes |
|-----------|------------|----------------|
| Desktop | > 768px | 3-column grids, sticky header |
| Tablet | ≤ 768px | 2-column grids, stacked header |
| Mobile | ≤ 480px | Single column, compact nav |
